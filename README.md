# Getting Started: ASP.NET Core

> **Course:** Dometrain | Getting Started: ASP.NET Core<br>
> `Getting Started` · `From Zero To Hero` ·<br>
> **Instructor:** Steve Smith

This course provides a foundational introduction to building web applications with **ASP.NET Core**, Microsoft's cross-platform framework for modern web development. It is designed to help learners understand the essential concepts required to create, run, and test basic ASP.NET Core applications.

---

## Key Topics

### 01 · Development Environment

Learn how to set up your development environment and ensure the necessary **.NET workloads** are installed and ready for ASP.NET Core development.

### 02 · .NET CLI

Use the **.NET CLI** to create, build, and run your first ASP.NET Core web application.

### 03 · ASP.NET Core Project Structure

Understand the core structure of an ASP.NET Core project, including important files such as:

* **Program.cs** — The main entry point and application configuration.
* **.csproj** — The project file containing project configuration and dependencies.

### 04 · Request Handling

Implement basic request handling to create simple **"Hello World"** style responses and understand how an ASP.NET Core application responds to HTTP requests.

### 05 · Application Lifecycle

Work with the application's lifecycle, run the application locally, and verify your progress by accessing it through a web browser.

---

## Course Information

This course, instructed by **Steve Smith**, provides a hands-on introduction to the ASP.NET Core ecosystem, guiding you through creating, running, and testing minimal web applications while building a solid foundation for further learning.
